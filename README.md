# webuntis-ical

**webuntis-ical is a script the reads your untis timetable and gives you a ics file**

## Dependencies
Install the required dependencies with `pip install -r requirements.txt` 

## Configuration

All config options can be found in `config.py`

To use the script you have to configure:
- username
- password
- server
- school
- timezone
- ics_location
- start and end date

All other options are optional

## Usage

After you configured everything in `config.py` you just have to run `main.py`
